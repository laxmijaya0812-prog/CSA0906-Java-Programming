# Assignment 3 Report Content

## Q1
ATM exception hierarchy, failure classification, catch ordering, finally guarantee, five test cases, and validation alternative are covered in Task01.

## Q2
User-defined checked exception hierarchy and exception chaining are implemented in Task02. `StorageDemo` produces the required success/error/cause behavior.

## Q3
Manual `try-catch-finally` and try-with-resources versions are provided in Task03. The comparison explains automatic closing and suppressed exceptions.

## Q4
Thread and Runnable implementations are provided in Task04. The life-cycle explanation covers start, run, sleep, isAlive and join.

## Q5
Unsynchronized and synchronized cinema seat booking programs are provided in Task05. The critical section and race condition are documented.

## Q6
Deadlock demonstration and producer-consumer token counter are provided in Task06. The token counter uses `while`, `wait()` and `notifyAll()`.

## Q7
Task07 implements a fault-tolerant processor using ExecutorService, Callable and Future. Sample corrupt and missing-file handling is included.

## Evidence to Add
The assignment requires actual execution screenshots, stack traces/logs, test tables and raw performance measurements. Add those from your own execution rather than using fabricated values.
